# Documentação

Esta pasta reúne a explicação da arquitetura e do estado atual do estudo de caso.

## Por onde começar

1. Leia [`current-state.md`](current-state.md) para entender o que existe hoje.
2. Consulte [`architecture.md`](architecture.md) para conhecer as responsabilidades e dependências.
3. Leia as decisões em [`decisions/`](decisions/) quando precisar entender o motivo de uma escolha estrutural.

## Conteúdo

- [`current-state.md`](current-state.md): fotografia operacional do projeto, fluxo atual e próximos passos.
- [`architecture.md`](architecture.md): componentes, fluxo de mensagens, persistência e regras de dependência.
- [`decisions/`](decisions/): registros das decisões arquiteturais importantes.

O [`README.md`](../README.md) da raiz continua sendo o ponto de entrada para execução do projeto.
