# Decisões Arquiteturais

Esta pasta registra decisões que explicam como o projeto foi organizado e por que determinadas alternativas foram escolhidas.

## Como ler

Cada decisão segue o formato ADR e normalmente contém:

- Contexto do problema.
- Decisão adotada.
- Consequências positivas e negativas.
- Regras derivadas para alterações futuras.

## Decisões atuais

- [`0001-shared-domain-and-contracts.md`](0001-shared-domain-and-contracts.md): separação do domínio e dos contratos em bibliotecas compartilhadas.

Ao alterar uma fronteira arquitetural, atualize ou crie um ADR em vez de registrar a decisão somente em código ou conversa.
